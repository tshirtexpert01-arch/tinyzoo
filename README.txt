TINY ZOO - ANDROID PROJECT (test ads, 7 languages, app icons)
1. In your GitHub repo: Add file > Upload files. Drag in: index.html, package.json, vite.config.js, capacitor.config.json and the folders  src,  resources,  public,  store,  voice-tools.  Commit.
2. Open .github/workflows/android.yml in the repo, click the pencil, delete everything, paste the contents of android.yml from this zip, and commit.
3. Actions tab > wait for the green check > download TinyZoo-apk.
4. UNINSTALL the old Tiny Zoo from your phone first, then install the new app-debug.apk.
Realistic voices: see voice-tools/README.txt.   Store images (Play icon 512, feature graphic): see the store folder.
